# 13 — Source attribution, current era, image rights, constraints

Source hierarchy for factual physical appearance:
1. User's own current labeled exterior photographs, with permission to use them as modeling references.
2. Current official SFU building information / architecture photographs, within permitted informational usage; do NOT paste images into textures or redistribute without rights.
3. City of Burnaby terrain/LiDAR/contour sources where conditions allow, documented horizontal/vertical coordinate references.
4. Appropriately licensed open map sources for shape/roads when already in baseline; follow OSM ODbL attribution and derived data rules when applicable.
5. Older virtual tour and user-provided map screenshots only for orientation and historic context, not current color/doors; do not scrape/copy Google Earth/Street View data or use them for texture reconstruction.
6. Unobserved details => `UNKNOWN`, estimated in original art only if needed for playability and labelled.

Log each source: `source_id`, URL or user_photo identifier, retrieved date, photographer/license, dataset era and CRS if GIS, part of model supported (e.g. color/entrance/level/footprint), any license restrictions, confidence. Old imagery showing buildings before modern towers must not override current records.

Project is a fan-made educational prototype, not an official SFU product. Don't copy protected SFU logo artwork without permission. No photos of students/residents or private rooms in textures, and no UI suggesting official affiliation.
