# 20 — Architecture-family workflow across Codex usage-reset iterations

**No 300-minute hard scope.** The user's five-hour interval is a usage reset, not an elapsed-time build budget. Work continuously through the task queue as access allows; each playable, checked-in milestone is a checkpoint rather than a reason to end the iteration. See `docs/PHASE2_22_USAGE_WINDOW_ITERATIONS.md`.

## Priority within the first allowance window
1. Verify/promote working nested Phase1 game and archive obsolete nested Markdown, leaving the original source game recoverable. Confirm `glxinfo -B` and preserved Compatibility backend.
2. Convert to strictly first-person controller and validate.
3. Model measured/credible hillside grade, pads and walking collisions; validate.
4. Correct concrete internal walkways, roads, curbs and parking LOT; validate.
5. Use photographs to refine ONE high-coverage reusable building family, default East/West; apply shared facade with instance differences, verify rooflines/entrances; validate.
6. **If usage remains, keep going:** polish verified details, fix QA regressions, or advance to North Towers or Townhouses rather than voluntarily stopping at an arbitrary elapsed time or single milestone.

## Subsequent allowance windows
At restart, read the current `docs/PHASE2_HANDOFF.md` and `docs/PHASE2_STATUS.md`, inspect current game + Git, and continue the **first incomplete task** without repeating already-finished research. Family order after East/West: North Towers (`Barbara_Pauline_Shadbolt/`) as ONE master; Townhouses as ONE configurable master; then Dining Commons, Courtyard, Shell House, Hamilton Hall, McTaggart-Cowan in evidence/impact order. Each family can be broken down into facade, entrances, surroundings and verification checkpoints, and work can spill into the next window. Never reconstruct each identical building independently.

If cap interrupts unexpectedly, rely on frequent persisted checkpoints. When a **real low-usage warning** appears, wrap up a small runnable change, test, update handoff and stop. The agent cannot reliably estimate remaining quota or schedule a future restart by itself. There is no guarantee of utilizing exactly all allowance or stopping a specified percentage below cap.

Roofline-aware reuse: one East/West master with official East 7 and West 8 storeys as sourced defaults; verify independently measured ground/foundation and roof Y rather than forcing photo alignment via an arbitrary offset. North Towers share a different 8-storey master and combined photo folder. Never add NPCs or online API implementation in this phase.
