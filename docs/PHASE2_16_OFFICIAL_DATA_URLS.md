# 16 — Credible sources worth checking (not pre-downloaded data)

These links point to external sources; Codex must verify status, access permission, date and data scope in its session. A URL listed here doesn't establish licensing or guarantee dataset coverage.

- City of Burnaby Maps and Open Data: https://www.burnaby.ca/services-and-payments/maps-and-open-data — includes LiDAR, terrain and 3D DEM categories.
- City of Burnaby 1m contours ArcGIS layer: https://gis.burnaby.ca/arcgis/rest/services/BurnabyMap/BBY_PUBLIC_TOC/MapServer/5 — layer's elevation attribute and EPSG:26910 must be confirmed at retrieval; dataset accuracy/rights to be verified.
- City of Burnaby 5m contours: https://gis.burnaby.ca/arcgis/rest/services/BurnabyMap/BBY_PUBLIC_TOC/MapServer/6
- City of Burnaby open data building outlines/LiDAR facets: https://gis.burnaby.ca/arcgis/rest/services/OpenData/OpenData4/MapServer — verify coverage/currentness.
- SFU official East + West Tower detail (East seven storeys, West eight): https://www.sfu.ca/students/residences/housing-options/east-west-towers.html
- SFU residence photo/architecture categories: https://www.sfu.ca/students/residences/housing-options.html
- SFU Courtyard Residence: https://www.sfu.ca/students/residences/housing-options/courtyard-residence.html
- Godot HeightMapShape3D for physics: https://docs.godotengine.org/en/stable/classes/class_heightmapshape3d.html
- Godot SurfaceTool class: https://docs.godotengine.org/en/stable/classes/class_surfacetool.html
- Godot rendering architecture, note Compatibility limitations (including decals): https://docs.godotengine.org/en/stable/engine_details/architecture/internal_rendering_architecture.html

Data conversion should avoid assuming data copyright/license is equivalent to visualization permissions. If datasets cannot be used, document why and use confidence-labeled procedural terrain approximations until source authorized.
