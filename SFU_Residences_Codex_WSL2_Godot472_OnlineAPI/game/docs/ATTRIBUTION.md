# Asset and data attribution

Contains information from **OpenStreetMap**, © OpenStreetMap contributors,
available under the [Open Database License 1.0](https://opendatacommons.org/licenses/odbl/1-0/).
See [OSM copyright and contributors](https://www.openstreetmap.org/copyright).

The raw extract `data/osm_source.osm` and the adapted geographic database
(`buildings.json`, `roads.json`, `site.json`, `test_routes.json`) are supplied in
machine-readable form under **ODbL 1.0**. Retain these files and this notice when
sharing the project or its produced scenery. If distributing an executable without
source, also offer the corresponding adapted database and transformation method
without charge online, with the ODbL notice. `scripts/import_site.py` in the package
reproduces the geographic transformation from the cached extract and original seed.
No additional restrictions are imposed on the OSM-derived database.

SFU and DIALOG pages were factual references; their photos, logos, videos, plans,
and page designs are not bundled as game assets. The supplied historic map and
modern screenshot remain outside `game/`; their presence in the instruction pack
does not grant redistribution rights. No Google/Street View imagery was traced.

Game geometry, procedural textures, character, plants, props and interface were
authored for this project. Game screenshots in this folder show this original
scene with OSM-derived placement. Engine-provided default font and sky are used.
No external texture packs, addons or downloaded character models are required.
This is an independent reconstruction study, not an official SFU product.
