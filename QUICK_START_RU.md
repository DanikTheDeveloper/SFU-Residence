# Быстрый старт — обновлённый Phase 2 (общие шаблоны зданий)

1. **Рабочая директория — ВНЕ старой вложенной папки**, на уровне где лежит новый `AGENTS.md`. Распакуй содержимое этого ZIP прямо туда. Он не содержит файлов игры и не должен перезаписать `game/`.
2. Если канонический `game/project.godot` уже есть с прошлой сессии — **не копируй повторно** старую игру. Если его нет, проверь `python3 scripts/promote_game.py --root .`, затем `--apply`, только после проверки источника.
3. `reference_photos/East_West_Towers/` — общая папка фотографий **East и West**, имена файлов должны указывать, какую башню видно. `reference_photos/Townhouses/` — все таунхаусы. `reference_photos/Barbara_Pauline_Shadbolt/` — **одна папка фотографий всех трёх северных башен** (Barbara Rae, Pauline Jewett, Shadbolt); указывай название здания в имени каждого файла. Остальные сооружения в собственных папках. `Dining_Commons/`, `Courtyard_Residence/`, `Shell_House/`, `Hamilton_Hall/`, `McTaggart_Cowan_Hall/` остаются отдельными — их нельзя моделировать как одинаковые таунхаусы.
4. Если фотографии уже лежат в СТАРОЙ структуре, используй `python3 scripts/relocate_legacy_photos.py --root .` (проверка), затем с `--apply` (копирование БЕЗ удаления и перезаписи).
5. Перед стартом Codex можно запустить `python3 scripts/validate_phase2.py`, `python3 scripts/validate_families.py`, `python3 scripts/photo_inventory.py --root .`, `bash scripts/check_wsl.sh`.
6. Главный принцип: **одна высококачественная модель для похожих зданий + параметры каждого отдельного здания**. Восточная башня 7 этажей, западная 8. Северные башни — отдельный общий тип (по 8 этажей согласно данным SFU), у каждой свой вход/позиция. Таунхаусы — общий тип, но с индивидуальными фундаментами и рельефом.
7. **Пять часов — период сброса лимита использования Codex, а НЕ лимит времени разработки.** В каждой итерации делай как можно больше полезной работы, пока доступен лимит. После каждого рабочего этапа сохраняй запускаемую версию, обновляй `docs/PHASE2_STATUS.md` и `docs/PHASE2_HANDOFF.md`; если появился настоящий сигнал о близком лимите — закончи маленькую операцию, сохрани результат и остановись. Codex не обязан знать остаток квоты и не может обещать автоматическое возобновление. При следующем окне пользователь снова запускает Codex, он читает handoff и продолжает с первого незавершённого пункта. Начни с миграции, вида от первого лица, горного рельефа, дорожек и парковки, затем общий тип здания по фотографиям. Если квота ещё есть — продолжай дальше, не останавливайся после одного здания. Интерьеры, NPC и OpenAI API пока НЕ реализуются.

Кодексу отправь содержимое `CODEX_TASK_PROMPT.md` из корневой папки. Вложенные старые Markdown-файлы — история, не инструкции.

## Высота East и West
По официальным данным SFU: **East 7 этажей, West 8 этажей**. Наблюдение пользователя о совпадении крыш учитываем, но утверждение «West выше по земле и на этаж ниже» противоречит опубликованным цифрам. Codex обязан сохранить этажность по документам как исходное значение, проверить реальную высоту основания по фото/данным рельефа, затем определить абсолютные высоты крыш. Не подгонять результат случайным перемещением зданий по Y. См. `docs/PHASE2_21_ROOFLINE_GRADE_AND_SOURCE_CONFLICT.md`.

Новые фото северных башен складывай **только** в `reference_photos/Barbara_Pauline_Shadbolt/`. Старые папки можно безопасно скопировать через `scripts/relocate_legacy_photos.py`; исходники сохраняются.
